# Household Chores Tracker

A family web application for managing shared household chores. Parents assign
chores to family members, chores can recur on a schedule, and completed work is
verified by a parent before points are awarded. Each member signs in with their
own account.

The full scope — the agreed v1 feature set and what has been deferred to a later
phase — lives in [`_docs/plan.md`](./_docs/plan.md).

## Status

Early planning. The scope is agreed; implementation has not yet begun.

## Scope at a glance

**v1 (in scope)**

- Individual accounts, with parent (admin) and child (member) roles
- Parent-assigned chores
- Recurring chores (daily / weekly)
- Parent verification before points are awarded
- A visible points tally per person

**Deferred to Phase 2**

- Reward catalogue and points redemption
- Points dashboard and leaderboard
- AI / agent features (natural-language entry, smart reminders, fairness
  suggestions)
